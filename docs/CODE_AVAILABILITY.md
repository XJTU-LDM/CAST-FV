# Code availability text

## Use after the GitHub repository is public

Replace `GITHUB_REPOSITORY_URL` with the final public URL:

> The source code implementing CAST-FV is publicly available on GitHub at GITHUB_REPOSITORY_URL.

Chinese reference translation:

> 实现 CAST-FV 的源代码已公开在 GitHub：GITHUB_REPOSITORY_URL。

This statement describes code availability only. It does not claim that CFD reference data, paper result archives, or model checkpoints are public.

## Preferred archival version

If a tagged release is later archived with Zenodo or another long-term repository, use:

> The source code implementing CAST-FV is publicly available on GitHub at GITHUB_REPOSITORY_URL. The version used for this study is archived at SOFTWARE_DOI.

Do not add a DOI sentence until the archive and identifier resolve publicly.
